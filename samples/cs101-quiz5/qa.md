## Version A

- (10 points) What is 9 plus 6?
  - **Correct**
    - 15
  - **Rubric**
    - Correct (+0)
    - Partially Correct
      - Off by one, such as 14 or 16 (-5)
      - Shows work but no final number (-5)
    - Incorrect (-10)
  - **Outcome** Number sense

- (10 points) What does CPU stand for?
  - **Correct**
    - Central Processing Unit
  - **Rubric**
    - Correct (+0)
    - Partially Correct
      - One word wrong, such as Computer Processing Unit (-5)
      - Describes what a CPU does instead of naming it (-5)
    - Incorrect (-10)
  - **Outcome** Computing basics

- (15 points) Which of these is a sorting algorithm?
  - **Choices**
    - A) Dijkstra
    - B) Merge sort
    - C) TCP
    - D) Huffman
  - **Correct**
    - B
  - **Rubric**
    - Correct (+0)
    - Partially Correct (-8)
    - Incorrect (-15)
  - **Outcome** Computing basics

- (25 points) Answer both parts.
  - **Outcome** Number sense
  - (10 points) What is 2 to the power of 5?
    - **Correct**
      - 32
    - **Rubric**
      - Correct (+10)
      - Partially Correct
        - Power of 2 off by one, such as 16 or 64 (+6)
        - Shows repeated multiplication but wrong product (+4)
      - Incorrect (+0)
  - (15 points) Convert binary 1010 to decimal.
    - **Correct**
      - 10
    - **Rubric**
      - Correct (+0)
      - Partially Correct
        - Missed one bit, such as 8 or 2 (-5)
        - Copies the binary digits as a decimal number (-10)
      - Incorrect (-15)

- (20 points) In a few words, what is a variable?
  - **Correct**
    - A named place that stores a value
    - A name that refers to a value
  - **Rubric**
    - Correct (+0)
    - Partially Correct
      - Mentions storing data but not the name (-8)
      - Only says it is a value (-12)
    - Incorrect (-20)
  - **Outcome** Computing basics

- (20 points) Write a Python expression for the last item of the list xs.
  - **Correct**
    - xs[-1]
    - xs[len(xs) - 1]
  - **Rubric**
    - Correct (+0)
    - Partially Correct
      - Right idea, wrong index, such as xs[len(xs)] (-10)
      - Another language's syntax, such as xs.last (-10)
    - Incorrect (-20)
  - **Outcome** Computing basics
